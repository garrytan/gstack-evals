# stack-neutral

This folder holds no procedure. It exists so that `gstack-evals skill-eval --lock` can pin the seeded-mistake tasks in ../tasks/ to a tasks digest and a policy without binding them to gstack's, pstack's or any other stack's skill text. The round 2 preregistration relocks the tasks against the arms it names and keeps the tasks digest.
