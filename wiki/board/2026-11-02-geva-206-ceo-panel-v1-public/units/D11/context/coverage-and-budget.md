# Coverage, delivery, and acceptance

The depot group has a signed desk-provider contract covering all eight sites. At the observed peak substitution rate, verification needs 111 cases per morning. The contracted team can handle 150 within current queue standards, and the full allowance is funded for four weeks. The provider has already staffed equivalent mornings. This remains available if a software installation or the group rehearsal needs more time.

The engineering estimate is thirteen engineer-weeks against sixteen assigned. The current appointment service has room for the added records and supports per-depot feature activation. Recorded load checks and permission tests run during development. No supplier agreement, security approval, carrier enrollment, or budget request is left for the final rehearsal.

Acceptance keeps desk-handled trucks in the outcome counts, checks identity exceptions, and compares queue time at similar volumes. The software has a reversible per-depot rollout. The old lookup and desk process remain supported through the next quarter, so a failed installation cannot remove the current operating service.
