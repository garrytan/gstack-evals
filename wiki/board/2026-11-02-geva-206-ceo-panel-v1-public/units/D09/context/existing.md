# Existing product

StepBirch has 1,800 paying adult class-booking users and 22 exercise providers. It already handles bookings, cancellations and personal payments. Employer-funded balances would be a new capability. Providers have signed an addendum allowing the same class price to be paid from a workplace balance.

The five proposed employers employ 260 current StepBirch users. Those users can keep their existing provider, account and class schedule. The administration fee is separate from class spending. No employee is required to participate.

The operations team can support the planned trial during existing weekday hours. The new feature does not need medical records, wearable data or a new exercise recommendation service. Unfunded employer bookings will not be accepted.
