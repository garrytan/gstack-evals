## S9 rule

THE RULE
1. Pairs: per creative model, every task graded in both cells (pairOnTasks, the scorer's pairing) whose successes differ.
2. Paths: each session's main-model turns in trajectory order (assistant messages without extra.dr_controller), each
   turn's commands joined by a newline and trimmed. The paths part at turn k, the first index where the two command
   sequences differ; if one is a prefix of the other, k is the shorter length; if they are identical, the pair is
   NEVER PARTED.
3. Window: in each routed session, the decisions logged after main turn k-1's response and before main turn k's response
   (decision t_ms against assistant extra.timestamp, both on the session clock t0 = end_ts - session_ms; a session with
   no turn k closes the window at its end). These are the decisions on turn k-1's commands and before query k, so the
   last decisions before the paths parted. k = 0 gives an empty window: FIRST TURN.
4. The window's kind is that of its last decision (by seq) that changed what the agent saw or did:
     done acted "done"                       SUBMIT LET THROUGH (the done check let the submit stand)
     done acted "third_submit_stands"        THIRD SUBMIT STANDS
     done acted "not_done"                   SUBMIT BLOCKED
     relevant, a dropped hit the real fix edits (grounded label)   DROPPED HIT IN THE REAL FIX
     relevant, other dropped hits            DROPPED HIT OUTSIDE THE FIX
     safe acted "blocked"                    BLOCKED COMMAND
     next_step with a guard                  LOOP GUARD
     next_step acted (a decider-run action)  DECIDER ACTION
   A window where no decision intervened is EXIT: the next-step layer handed the turn to the main model and nothing a
   decider did changed what it saw (the exit-storm kind; the main model's own turn). Detail: whether the window's
   next_step deciders all picked the exit, or one picked an action that no acting band let act.
5. Pair kind: R against N reads R's window (N logs no decisions). R against P reads both windows; the pair kind is the
   side that intervened, both named (R first) when both did, EXIT when neither did.
6. Beside it, a second trace that is not about the parting point: the last intervening decision anywhere in the failing
   routed session (R in R against N; whichever of R and P failed in R against P), same table, with its grounded label.

(b) exposure: how many routed sessions in discordant pairs had each intervention kind anywhere, against all routed
