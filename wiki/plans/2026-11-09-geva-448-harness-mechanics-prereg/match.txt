# gstack (lib/skill-contract.ts at 350d4196) tests it with flag i against each Bash command after the last edit,
# after replacing every quoted string with "" (double-quoted with escapes, or single-quoted). It replaces gstack's
# built-in classifier, so it has to count /verify's own gstack-checks run forms as well as the test runners and the
# repro forms the scorer counts. In the case lines, a backslash n stands for a newline inside the command, and a
# case's command is the rest of its line after the label and one space, leading spaces included. Because gstack
# compiles the regex with flag i, the whole regex sits in a (?-i:...) group and matches case-sensitively, so pytest -V
# (a version probe) doesn't count and pytest -v (a run) does. The engine is Bun's: the hook runs under Bun at the build
