# Probe set and timing cases for match.txt's regex (section 6, dry-run step 3). The regex is match.txt's.
# BEFORE is match.txt's regex before its scans stopped at separators (match.txt at sha256 5621d45ce9a247b483c9e640d7e2151e63a8eb02d5ef94553bc688d842547312).
# Every command gets match.txt's quote transform first. A backslash n, r or t stands for a newline, carriage return
# or tab, and a case's command is the rest of its line after the label and one space. 21 prefixes stand in front
# of 9 commands.
# COUNT and NO: the regex and BEFORE both put the command on that side, under Bun and under Node.
# FLIP: BEFORE counts the command and the regex doesn't. These are the only expected changes: an env assignment
# whose value holds $(...) or <(...) in front of a check (a known miss, the same in every arm), and FOO=a;b or
# FOO=a|b in front of one, where what runs is b, not the check.
# TIME n u: the command is "cat > x <<EOF", a newline, then u repeated to n characters. The regex finishes each in
