What gets published: the harness, the arms file, the unit lists with digests, the frozen scripts, and per session the diff, score record, cost, exposure markers and a tool-event summary. Not published: full transcripts (they quote issue text, repository code and pack skill text under mixed terms), images (Claude Code is proprietary and the images' dependency licences are unreviewed) and B1 issue text. Everything published passes a secret scan and a personal-data scan.

None of these terms bars this eval, which trains nothing and publishes rates, diffs of permissively licensed code with their notices, and task ids.
